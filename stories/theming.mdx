# Theming

daemon-ui uses CSS custom properties via Tailwind 4's `@theme` directive with `light-dark()` functions for automatic dark/light mode.

## ThemeProvider

Wrap your app with `ThemeProvider` to enable theme switching:

```tsx
import { ThemeProvider } from '@dmm1/daemon-ui'

;<ThemeProvider defaultTheme="dark">
  <App />
</ThemeProvider>
```

### Props

| Prop           | Type                            | Default             | Description           |
| -------------- | ------------------------------- | ------------------- | --------------------- |
| `defaultTheme` | `'light' \| 'dark' \| 'system'` | `'dark'`            | Initial theme         |
| `storageKey`   | `string`                        | `'daemon-ui-theme'` | localStorage key      |
| `colors`       | `ThemeColors`                   | —                   | Override color tokens |
| `typography`   | `ThemeTypography`               | —                   | Override font tokens  |

## useTheme Hook

```tsx
import { useTheme } from '@dmm1/daemon-ui'

function ThemeToggle() {
  const { theme, resolvedTheme, setTheme } = useTheme()
  return (
    <button
      onClick={() => setTheme(resolvedTheme === 'dark' ? 'light' : 'dark')}
    >
      {resolvedTheme === 'dark' ? 'LIGHT' : 'DARK'}
    </button>
  )
}
```

## Custom Colors

Override colors at the provider level:

```tsx
<ThemeProvider
  defaultTheme="dark"
  colors={{ primary: '#ff6b00', success: '#00ff88' }}
  typography={{ fontMono: "'Fira Code', monospace" }}
>
```

Or override via CSS:

```css
:root {
  --color-primary: #ff6b00;
  --font-mono: 'Fira Code', monospace;
}
```
