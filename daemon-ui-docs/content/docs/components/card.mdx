---
title: Card
description: Container component with panel background and HUD-style borders.
---

## Import

```tsx
import { Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter } from '@dmm1/daemon-ui'
```

## Usage

```tsx
<Card>
  <CardHeader>
    <CardTitle>SYSTEM STATUS</CardTitle>
    <CardDescription>Real-time monitoring data</CardDescription>
  </CardHeader>
  <CardContent>
    <p>All systems operational.</p>
  </CardContent>
  <CardFooter>
    <Button variant="outline">REFRESH</Button>
  </CardFooter>
</Card>
```

## Variants

```tsx
<Card variant="default">Default card</Card>
<Card variant="outline">Outlined card</Card>
```

## API Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `'default' \| 'outline'` | `'default'` | Card style |
| `className` | `string` | — | Additional CSS classes |
| `children` | `ReactNode` | — | Card content |
